## GPT 日程导入格式规范 v1.0

将此规范提供给 GPT，让其生成可直接拖入"日程管理系统"的格式化文件。

---

### 支持的格式

| 格式 | 后缀 | 推荐场景 |
|------|------|----------|
| JSON | `.json` | 结构化数据, 精确导入, 推荐首选 |
| Markdown | `.md` | 自然语言生成, 周计划/月计划列表 |
| XML | `.xml` | 与其他系统对接 |

---

### JSON 格式 (推荐)

```json
{
  "events": [
    {
      "title": "项目评审会议",
      "date": "2026-05-26",
      "start": "10:00",
      "end": "11:30",
      "category": "工作",
      "location": "会议室 A",
      "description": "确认里程碑和风险点"
    }
  ]
}
```

**字段说明:**

| 字段 | 类型 | 必填 | 最长 | 说明 |
|------|------|------|------|------|
| `title` | string | **是** | 160 | 事件标题 |
| `date` | string | **是** | -- | 日期, 格式 `YYYY-MM-DD`, 也支持 `YYYY/MM/DD`, `YYYY.MM.DD`, `YYYYMMDD` |
| `start` | string | 否 | -- | 开始时间, `HH:MM` 24小时制, 步长30分钟 |
| `end` | string | 否 | -- | 结束时间, 必须晚于 `start` |
| `category` | string | 否 | 80 | 分类, 默认 `General` |
| `location` | string | 否 | 160 | 地点 |
| `description` | string | 否 | 2000 | 备注描述 |

**类目建议值:**
`工作` `学习` `健康` `社交` `娱乐` `休息` `家务` `通勤` `个人` `会议` `阅读` `运动`

**别名支持:** 以下旧字段名也会被识别:
- `title` → 也接受 `name`, `event`
- `date` → 也接受 `event_date`, `day`
- `start` → 也接受 `start_time`, `from`, `time`
- `end` → 也接受 `end_time`, `to`
- `category` → 也接受 `type`
- `location` → 也接受 `place`
- `description` → 也接受 `notes`, `detail`

**根对象兼容:**
- 数组: `[{...}, {...}]`
- 对象(events键): `{"events": [...]}`
- 对象(schedule键): `{"schedule": [...]}`
- 单个对象: `{"title": "...", ...}`

---

### Markdown 格式

适合 GPT 以自然语言风格生成周/月计划。

```markdown
# 2026-05-26

- 10:00-11:30 项目评审 | 工作 | 确认里程碑
- 14:00 团队周会 | 会议 | 同步本周进度
- 19:30 跑步 | 健康

# 2026-05-27

- 09:00-12:00 代码审查 | 工作
- 15:00-16:00 客户演示 | 工作 | 会议室 B
```

**解析规则:**
- `#` 开头的日期行 (支持 `YYYY-MM-DD`, `YYYY/MM/DD`, `YYYY.MM.DD`)
- `-` 或 `*` 或 `1.` 开头的列表项解析为事件
- 时间格式 `HH:MM-HH:MM` 或 `HH:MM`
- `|` 分隔的三个字段: `标题 | 分类 | 备注`

---

### XML 格式

```xml
<events>
  <event>
    <title>团队站会</title>
    <date>2026-05-26</date>
    <start>09:30</start>
    <end>09:45</end>
    <category>会议</category>
  </event>
  <event title="午餐" date="2026-05-26" start="12:00" end="13:00" category="休息" />
</events>
```

支持 `<event>` 节点, 属性或子元素均可。

---

### GPT Prompt 模板

将以下 prompt 发给 GPT 生成日程数据:

```
请根据以下信息生成一个 JSON 格式的日程文件, 用于导入日程管理系统:

[在此描述你的日程安排, 可以用自然语言, 例如:]

"下周一到周五, 每天 9:00-10:00 晨会(工作),
周二和周四 15:00-17:00 深度学习(学习),
周三 19:00-20:30 瑜伽课(健康, 地点: 健身房),
每天 12:00-13:00 午餐(休息)"

要求:
1. 输出完整的 JSON, events 数组
2. 日期使用 YYYY-MM-DD 格式
3. 时间使用 HH:MM 24小时制
4. 分类使用中文: 工作/学习/健康/社交/娱乐/休息/家务/通勤/个人/会议
5. 如果有地点和备注也请补充
```
